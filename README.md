# Long-Distance Universality for the Berger Sphere and the Unicycle

Deep Bhattacharjee

Proofs of two claims of Brown, Freedman, Lin and Susskind (Nature 622, 2023) on one-qubit complexity geometry: the Berger-sphere distance moves by at most π/(2√I) as I → ∞ (sharp to leading order), and the unicycle parking cost is z + 2√(1−1/I) + O(1/z).

- `paper/` LaTeX source and figures (pdflatex)
- `preprints/` PDF and source zip
- `code/figures.py` draws the figures (`python3 code/figures.py paper`)
